# AfriConnect Summit 2026

## Description

AfriConnect Summit 2026 est un site web vitrine présentant une conférence internationale consacrée aux technologies numériques, à l'innovation et à l'entrepreneuriat en Afrique.

Le projet a été réalisé dans le cadre du module de Développement Web.

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

---

## Fonctionnalités

- Navigation responsive
- Mode sombre
- Menu mobile
- Compte à rebours
- Animations au scroll
- Onglets du programme
- Filtrage des intervenants
- Validation du formulaire
- Bouton Retour en haut
